# To-Do List – Week 7 Assignment

A premium to-do list application with:
- ✅ Add, delete, and complete tasks
- ✅ LocalStorage persistence (tasks survive page refresh)
- ✅ Filter by All / Active / Completed – **filter preference is also saved**
- ✅ Clean module separation (storage.js + app.js)
- ✅ Created timestamp for each task

## How to run
Open `index.html` with **Live Server** in VS Code (because of ES modules).

## Technologies
- HTML5 / CSS3
- Vanilla JavaScript (ES6 modules)
- LocalStorage API
